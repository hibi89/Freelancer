# 기술 선택·비용·상업 라이선스 게이트

## 1. 아키텍처 계약
UI→AudioSessionCoordinator→(ASR/AnimalEvent)→LocalDialogLLM→(HumanVoiceTTS/CharacterTTS)→AudioOutput. 각각 별도 인터페이스, 업로드·네트워크 전송 구현 없음. 후속 cloud adapter는 독립 모듈로만 추가 가능하며 명시적 사용 동의, 비용/데이터 안내, 서버키 보안 설계를 별도 승인받는다.

### 후보 모델 (미채택)
- 한국어 STT: 오프라인 ASR 프레임워크 후보는 Whisper 계열/whisper.cpp 등. 공개 코드와 **모델 가중치 라이선스는 별개**.
- LLM: 국문 응답 가능한 로컬 소형 instruct 모델 후보를 CPU/GPU와 한국어 대화 품질로 비교. 모델명 및 사양 미확정.
- 가족 TTS: zero-shot voice-conditioned 한국어 지원 모델 후보를 최소 샘플/동의·상업 재배포 조항/추론속도·유사도로 평가. XTTS/F5-TTS/기타는 '후보'일 뿐 라이선스·출고 적합성 확인 전 번들 금지.
- 캐릭터 TTS: 상용 이용 가능한 일반 한국어 TTS(가족 TTS와 엔진을 공유하거나 경량 대체).
- 동물 이벤트: 가벼운 로컬 분류기/음향 이벤트 탐지. 질병/의사 해독 라벨은 학습 목적 자체에서 제외.
- Windows: Python 3.11 기반 패키징 vs 다른 런타임 비교, 서드파티 DLL/FFmpeg 관련 라이선스/재배포/취약점 확인.

## 2. 비교표
| 설계 | 장점 | 단점 | 총비용/결정 |
|---|---|---|---|
| A: 오프라인 통합 바이너리+검증된 모델팩 | 개인정보 보호, 판매 후 API 변동비 없음, 오프라인 재현 | 설치용량·RAM·CPU 병목, 모델 공급과 업그레이드 | 우선 채택 |
| B: 로컬 프런트+외부 인퍼런스 | 빠르고 일반 PC 자원 적음 | 실 API요금, 목소리/질문 외부 전송, 규제·중단위험 | 1차 불채택 |
| C: 사전녹음/고정 템플릿 | 매우 가볍고 저렴 | 대화형 AI 요구 충족 안 됨 | 불채택 |

구매자별 비용: A는 외부 토큰 비용 0을 목표로 하지만 디스크/전력/판매자 기술지원·소프트웨어 업데이트 비용은 발생. 30,000원에서 수수료/환불/지원 원가를 차감해야 하므로 판매이익 미검증.

## 3. 성능 검증 플랜
- 프로필: Windows 10/11 x64, 8GB/16GB/32GB RAM과 CPU-only / GPU 가속 조합을 테스트 가능한 장치부터 실측.
- 지표: 설치 크기·시작시간, CPU/GPU 메모리 최대치, p50/p95 첫 응답 지연, 실시간 합성 지연, 한국어 STT 단어 오류, 화자 유사도(블라인드 평가), 잡음 입력 실패율, 반려동물 false positive/negative, 복구 후 사용가능 여부.
- 합격 기준은 실제 데이터 측정 후 최소/권장 PC별 사용자 승인. 미측정 지표 수치 임의 약속 금지.
- 샘플 1개/2개, 5초/15초/60초 등 여러 길이·잡음·음성 특성을 대상으로 적합성 평가. 1~2파일 입력은 **지원 목표**이지 모든 파일의 완전한 동일음색 보장 아님.

- research-only/noncommercial/상업재배포불가/별도 서비스 약관과 충돌: 출시 패키지에서 제외.

## 5. 장애·복원·버전
모델 미설치/깨짐: 체크섬 불일치→로컬 모델팩 재설치 안내, 임의 네트워크 다운로드 금지.
GPU OOM: 작업 취소→자원 안내→검증된 CPU/작은 모델 폴백; 기존 프로필 보존.
녹음 품질 나쁨: 파일 추가 요구를 강제하지 않고 품질 불가/기본 목소리 사용 고지.
오디오 장치 없음/권한 거부: 텍스트 입력·기본 TTS 재생 옵션.
릴리즈: 설치 전/후 파일 SHA, 사전 백업·유저 데이터 비파괴 migration, 1단계 복구와 안전제거 시험.

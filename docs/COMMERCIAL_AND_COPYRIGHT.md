# MYRADIO AI — 저작권/판매 정책 (RELEASE HOLD)

MYRADIO는 음악 소유권을 판매하는 것이 아니라 AI DJ 소프트웨어를 판매한다. 앱 코드 상업적 배포와 실제 녹음 음악의 앱 내 재생/자동 제공/원격 스트리밍 권리는 별도다. '무료'·'NCS'·'저작권 없음' 등으로 혼동하면 안 된다.

1. 출처별 원본 제공자 약관/공식 API 이용조건·쿼터·스트리밍·임베딩·다운로드 허용/금지 확인. 작품 저작권과 녹음/실연자/음반제작자 권리 확인; 미확인 곡 자동 차단.
2. 검색된 오픈 라이선스 라벨은 진짜 권리 검증 증빙이 아님. 원본 URL·라이선스 버전·권리자/출처·확인 시점 기록. CC BY는 저작자·곡명·원본과 라이선스 링크, 변경 여부 표시. CC0도 실제 사용 권한 및 호스팅 약관 확인 필요.
3. BY-NC, 상업적 자동 재생 범위가 불명확한 NCS, DRM 보호, 광고 은닉을 요구하는 서비스 등은 공식 허가 없으면 판매형 앱에서 제외.
4. 사용자가 직접 지정한 로컬 파일은 개인용 재생으로 제한, 앱의 음악 재판매/클라우드 업로드/대량 복제 권한과 구분. 해당 오디오 GitHub 커밋 금지.
5. Qwen3-TTS/CosyVoice 등 이름만 보고 상업용 허가 단정 금지. 코드/모델 가중치/재배포/음성 및 학습 데이터 라이선스, 실제 PC 성능·작품 권리 종합 확인 뒤 채택. 실존 DJ 음색 사칭 금지.
6. 개인용 프로그램에서도 불법 음원 다운로드·사이트 자동접속 금지 조항은 별도 적용. 한국 저작권법·AI 생성 음성 고지·개인정보·고객 환불 정책 법률 검토 필요.
7. 사용자 희망 판매가 30,000원(확정 판매가 아님). 판매 전 크몽 등록/중복 서비스/수수료·부가세·설치 지원·업데이트/환불·이용약관 및 최소 사양 확인.
8. 등록 상태는 실제 크몽 게시/심사 증거 없으면 '미등록'; 판매중지/기록은 삭제하지 않는다. 상품 홍보는 실제 검증된 기능만 기술.

판매 승인 전 현 상태 RELEASE HOLD. 법적 자문 완료를 의미하지 않는다.

# 수용테스트 · 증거 매핑 (모두 NOT_RUN)

테스트는 Python 단위→Windows GUI/E2E→오프라인/보안→실고객 장치 순. 실측 전 PASS·95% 주장 금지.

## 공통 C01~C12
1. C01 Windows 10 설치/초기 실행/삭제, 사용자 기존 파일 무변경.
2. C02 Windows 11 설치/초기 실행/삭제, 사용자 기존 파일 무변경.
3. C03 인터넷 차단 상태로 모델팩 설치 후 STT→LLM→TTS 성공.
4. C04 방화벽/패킷/로그 점검 결과 개인 음성·질문 외부전송 0건.
5. C05 마이크 권한 거부 후 crash 없이 텍스트 입력으로 대체.
6. C06 장치 변경/마이크 제거/무음 중복 입력 후 상태 복구.
7. C07 실행 중 임의 종료/재시작 후 앱·원본 무결성.
8. C08 로컬 사용자 프로필 삭제·캐시 삭제·재설정.
9. C09 양 SKU 개별/묶음 기능 접근·가격 표시/업그레이드 경로.
10. C10 모델 파일·의존성 checksums/NOTICE/상업재배포 검증.
11. C11 큰 파일/잘못된 확장자/오디오 파서 취약입력 방어.
12. C12 한국어 대화 품질/응답지연/메모리/디스크/발열 실측.

## 가족 F01~F10
13. F01 깨끗한 샘플 1개(길이별) 등록/미리듣기/합성 품질.
14. F02 깨끗한 샘플 2개 등록/교체/재현/취소.
15. F03 잡음·혼합 화자·무음·손상 오디오 거부 및 가이드.
16. F04 원본을 읽기만 하며 원래 저장 위치 파일 변형 없음.
17. F05 등록 음색 출력과 AI 답변 텍스트 일치.
18. F06 새 채팅 시작 시 생전 기억/개인 데이터 사칭 없음.
19. F07 AI 음성·내용 고지 재생화면과 시작화면 표시.
20. F08 권리 확인 없이 임의 제3자 목소리 등록 허용하지 않기.
21. F09 특성 데이터/원본 캐시 완전 정리 및 기본 음성 폴백.
22. F10 음성파일/합성 모델 처리 장애 복구 후 다른 기능 정상.

24. P02 고양이 울음 이벤트 인식 및 놀이형 응답 고지.

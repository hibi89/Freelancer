# SITECRAFT AX — 상용 브랜드·포지셔닝

- **상품명(내부 확정): SITECRAFT AX**
- **고객용 한글명:** 웹사이트 진단·독립 재구축 서비스
- **핵심 조합:** REA_WEB + Fable 5.1(정적 관찰) + Playwright(실브라우저) + Astra P4(사실/추정·증거) + 인간 명세 승인 + REA Pro(FastAPI/SQLite 독립 빌더).
- **핵심 고객 결과:** 정당한 권한이 있는 기존 사이트를 관찰해 동작·모바일·품질·기능 명세를 증거화하고 고객이 승인한 범위만 별도 코드로 재구축·검수.
- **간단 소개:** "기존 웹사이트를 증거로 진단하고, 승인된 요구사항에 맞춰 새 사이트로 재구축."
- **표준형 목표 견적:** 1,890,000원, 최대 7페이지와 합의된 기능 흐름. 관리자 CRUD/회원 인증/결제/실 DB 이관은 별도 검증/견적.
- **기술과 구분:** `hibi89/REA_Web`의 원형 웹사이트 분석·재구축 기술을 이용하며 `hibi89/data2web_studio`의 CSV·Excel 데이터 페이지 생성 상품과 혼동하지 않는다.
- **한계:** 공개 URL만으로 숨은 서버 소스, DB, 모든 화면 기능/저작권을 획득할 수 없음. 무단 복제·픽셀 동일성 보장·타인 콘텐츠 무허가 재사용 금지.
- **진척 기준:** 제품 `docs/FINAL_BLUEPRINT.md` 전체 수용표, 이름 변경만으로 기능 점수 변동 없음.
- **상표/권리:** 상표·도메인·동명 서비스 조회 전 내부 작업명. 고객 사이트 사용권과 이미지·폰트/브랜드 자산 라이선스 확인 전 RELEASE HOLD.
- **변경 범위:** `product/rea-website-rebuild` 브랜치와 기존 기술 원본 SHA/테스트·Production 보존.

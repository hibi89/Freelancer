# 기업 RAG 크몽 판매 범위·가격·라이선스·증빙

## 1. 가격 (시세가 아니라 타당가 견적 가설)
| 등급 | 금액 | 고객 납품 범위 | 반드시 제외/별도 견적 |
|---|---:|---|---|
| BASIC | 1,490,000원 | 로컬 1인 PC·고객 허가 문서 최대 200쪽(지원 포맷)·BM25/정확 출처·설치 가이드·검수 | 멀티사용자 ACL, 자유 LLM, 서버 |
| STANDARD | **2,990,000원** | 승인 문서 **최대 1,000쪽**, 실제 고객 사용자 **최대 10명**, 역할 기반 읽기 권한, SQL+문서 지원된 질문, 원문 인용·업데이트·교육/검수 1회 | 대규모 SSO/SIEM, 고성능 GPU, 비지원 ERP/무제한 LLM |
| PREMIUM | 5,990,000원 | 최대 50명(고객 서버 자원 충족 시), 부서별 컬렉션, 선별 로컬 모델·고급색인, 감사/백업·복구와 품질 리포트 | 보안인증 보증, 24/7 SLA, 광범위 원문 OCR/영상 |

**특히 STANDARD의 다중 사용자 ACL은 아직 신규 개발·검증이 필요한 조건**이다. 해당 Gate 미달 시 해당 등급 판매 금지 또는 계약 범위/금액 재승인. 페이지 수는 PDF 추출분 기준인지 문서 실제 인쇄 페이지 기준인지 명시.

## 2. 공급사 대비 고객 가치 검증 목표
- Dify/AnythingLLM/RAGFlow류에도 RAG, 인용, 로컬 구성 등 많은 유사 기능이 있다. **세계최초/독점** 주장 금지.
- 우리가 입증할 것은 ①회사 데이터 권리 승인·버전/폐기 ②정확 매출 SQL와 문서 근거 결합 ③문서 누출 방지 ④설치·인수/업데이트 검증 ⑤고객 업무형 100질문 리포트 ⑥원본 보존·장애 복구.
- 동일 자료/질문으로 기존 제품과 성능/정확/지원비 비교, 독립 audit와 고객 1차 승인 없으면 우위 주장 보류.

## 3. 개인정보·보안·접근정책
- 기업 자료 수집 전에 처리 목적·사용권·접근 가능 사용자·보유기간·파기/재색인 요청·모델 전송범위·계약자 개인정보 처리 위탁 여부 확인.
- 고객 로컬 권한 강제, API 인증·세션 폐기, 검색 단계 document ACL, 임베딩/캐시 자체 권한 분리, PDF/DOCX 공격 표면, 정형 DB SELECT 쿼리 허용목록.
- 생성 모델 가중치, 데이터셋, 패키지, 폰트 등의 상업 재배포 라이선스/NOTICE/제3자 고지 검증. 리포 상 LICENSE가 없으면 사용권 자동 허락 아님.
- 민감 고객 원문/행, token, private SMAX, 직원 신원/암호를 GitHub/AI 대화로 옮기지 않음.

## 4. 지원·거래조건
- 설치·운영 장비 CPU/RAM/저장공간과 파일 용량을 견적 직전에 실측. 모델 GPU/전력·서버·매달 유지·원격지원·유료 API 비용 별도.
- 수용 범위: '문서 수/형식/페이지', 검색 Gold 질문, 권한 수/조직 수, 문서 교체 지원, 설치/재설치 횟수, 수정 1회, 지원 기간을 서면 고정.
- 실제 고객 원본 데이터를 테스트할 때 계약/보안 승인 후. 납품 시 파일 SHA/검수표·운영/재색인·오프라인 복구·로그/삭제 정책 제공.
- 판매자 사업자등록/세금계산서 발급 가능 여부는 실제 과세유형·크몽 증빙 정책 확인 후 안내; 불가능한 증빙 제공 약속 금지.
- 정식 출고까지 `RELEASE HOLD` 유지, 기존 개인용 상품 가격/기능/고객 승인과 혼동하지 않는다.

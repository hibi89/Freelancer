# HAE 크몽 판매 설계 / 지원·법률·보안

## A. 패키지와 가격 (검증 전 전략적 제안가)
| 등급 | 판매가 | 포함 기준(검수 범위 고정) | 제외 |
|---|---:|---|---|
| BASIC | 990,000원 | 지원된 로컬 템플릿 1개, CSV→SQLite 1종, 설치·동작 증명 1회, 수정 1회 | SaaS OAuth, 복합 DB |
| STANDARD | **1,990,000원** | 지원된 워크플로 **2개**, 승인형 입력/출력, 지원되는 연동 **최대 2개**, 실행 이력/복구 가이드, 고객 인수 시나리오 2개 | 임의 ERP/PG/외부 결제, 24시간 관제 |
| PREMIUM | 3,990,000원 | 지원된 워크플로 최대 4개, 위험 승인 단계·관제/감사 옵션, 조건부 DBVORA 어댑터, 인수 리허설 | 비지원 SaaS, 무기한 개발·운영·무제한 수정 |

**'연동'은 실제 기능/인증/권리를 사전에 검증한 목록에 한정**. 외부 사용료(LLM API, 서버, OAuth 앱/계정, 기업 보안 심사), 도메인, 유료 라이선스, 세금·수수료는 견적과 계약에서 별도 표기. 기술이 미완성인 경우 등급 전체를 즉시 판매하지 않는다.

## B. 3개 고객 사례와 수용
1. 소규모 온라인 판매자: 주문 CSV 표준화→중복검사→승인 후 SQLite→일일 매출 집계. 100건 샘플과 실제 입력 스키마 통과, 중복 run 2회 시 행 변화 없음.
2. 회계 보조: 공급사 CSV→정합성/매핑 검토→월별 별도 보고. 원본 보존, 금액/세금 판단은 회계 담당자 승인 필요.
3. 지원팀: 승인된 Sheets 읽기→서식 전환→파일 출력, Gmail 발송은 실 OAuth 통과 후 고객의 사람 최종 승인 없이는 전송 금지.

## C. 계약 필수 항목
- 입력 형식·월 처리량·주기·경로/인증·최대 워크플로/조건/연동·완료 기준·예외 파일·데이터 보관 범위.
- 개발 완료가 아닌 **수용 시나리오별 통과**가 납품 기준. 설치 전/후 고객 백업 검증, 실패 시 원복.
- 고객 제공 계정의 로그인·권한·비밀번호는 고객이 직접 처리, 시크릿 미인수 원칙.
- 수정 횟수 및 범위, 오류 수정과 신규 기능의 구분, 납품 후 지원 기간, SLA(없으면 없다고 표기), 라이선스·재배포권·세금증빙 조건.
- 개인정보 처리 위탁, 제3자 전송, 프로그램 모델 사용권·고객 제공 데이터 권리, AI 활용 고지 필요성 검토.
- 개인판매자 거래·증빙 제약은 현재 크몽 정책과 국세청 등록/과세유형을 계약 직전에 재확인. 세금계산서 발급 가능하다고 약속하지 않음.

## D. 경쟁 대비 차별성 검증 실험
비교 후보는 n8n/Make/Zapier/맞춤 Python; **성능 우위 미검증**. 공평한 동일 입력/결과로 (1) 첫 설정 시간, (2) 총 고객 개입, (3) 실패·재실행 누락/중복 수, (4) 월 외부 비용, (5) 복구 설명서 품질, (6) 비밀 유출 검출을 계측한다. 지원되지 않는 SaaS는 비교에서 제외하거나 범위를 명시한다.

가격은 **우리가 수행할 고객 검수 시간과 데이터 위험을 반영한 임시 가설**이며, 실제 수요·경쟁거래액·개발비 회수/지원/플랫폼 수수료 미측정. 판매 전 상향/하향 가능. 고객의 데이터 양/정제 난이도·원본 형식과 세금/수수료 별도로 확인.

## 서비스 품질 보증의 범위
- 보장하려는 것: 지원 범위의 원본 무변경, 승인 산식/독립 계산 일치, 명시적 유효성 검사/모델 실험 재현, 고객이 납품 파일을 열고 읽을 수 있음.
- 보장하지 않는 것: 반드시 정확한 미래 매출/주가·고객 행동 예측, 매출 증가, 데이터 자체 사실 정확성, 법률·세무 확정, 개인별 차별적 고객 타깃팅, 사업 파산 방지.
- 고객이 제공하는 영수증/장부/실거래 데이터의 진본성은 우리가 별도 검증하지 않는 한 **고객 제출 자료 기반**이라고 표시.

## PII/보안 법률·모델 라이선스
- 외부 모델 기본 OFF, 고객 서면 동의 없이 제3자 생성 모델로 고객정보 보내지 않는다.
- 성명/연락처·정부식별정보·특별 개인정보는 별도 처리 목적·법적 근거·가명화/비식별·접근권한·보유/파기 정책이 없으면 접수 불가.
- NVIDIA/auto-ontology Apache-2.0은 프로젝트 코드에 대한 라이선스이고, NVIDIA NIM 모델·API·배포 인프라 사용료/라이선스까지 포괄 보장하지 않음. 개념을 직접 구현할 때에도 출처를 설명·상표제휴 주장을 하지 않는다.
- openpyxl/pandas/sklearn/PDF/폰트/GUI/installer 등 실제 종속성 LICENSE/NOTICE 및 최신 CVE, 고객 데이터 권리/수정권·가공정보 전달 조건을 라이브 출시 전에 확인.
- 크몽 개인전문가 증빙/세금계산서 가능 여부·고객 사업자 요구는 실제 등록 상태와 최신 규정 재확인 후 계약 전 명시. 무단 발급 약속 없음.

## 고객 분쟁·변경 통제
- 견적서에 정확한 입력파일 수/시트/최대행수/통화·기간·산식·보고서/예측 범위/재수정 1회·검수 완료 기준/지원기간/삭제정책을 고정한다.
- 고객의 'CSV 올리면 AI가 모든 예측' 같은 주문은 정의가 불명확하므로 우선 요청을 수치/질문/목표/데이터 범위로 제한한다.
- 모델이 자료 부족으로 예측 실패 시 억지 결과 대신 `ML_NOT_SUITABLE`와 원인·필요 데이터, 승인된 대체 통계 리포트 제공.
- 데이터 삭제/보관을 포함한 인수서·정확 ZIP SHA/PDF/Excel 열기 확인과 권리 승인 후 상품 출시.

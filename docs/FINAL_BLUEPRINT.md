## 1. 상품 정의와 핵심 목표

사용자가 '오늘 잠이 안 오니 2시간 잔잔한 재즈', '비 오는 오후에 어울리는 음악', '아침에 신나는 음악' 등을 음성 또는 텍스트로 요청하면 개인 라디오 방송국의 AI DJ가 장르·기분·시간·취향·청취 기록을 반영해 합법적인 음원을 찾고 곡을 소개한 뒤 실제 재생한다. 곡이 끝나면 자연스러운 연결 멘트와 다음 곡을 진행한다. **실제 방송인처럼 들리는 여러 DJ 음색/화자**와 톤·말 속도·감정·멘트 길이를 설정할 수 있고, 청취자가 말을 걸면 대답하고 재생목록도 조정한다.

최우선: 음악 제작 없이 무료 오픈 라이선스 음원과 사용자가 적법하게 보유한 로컬 음악 활용. Openverse, ccMixter 등 공식 API/원본 허가 범위에 따라 연결. 실재 곡의 음악 저작권·녹음권·호스팅 조건과 앱에서 재생할 수 있는 권한을 구분. **무료 감상만으로 앱 내 자동 재생/재중계 권리가 발생하지 않는다.**

가정: Windows 개인 PC, 한국어 우선, local-first, 월 구독·유료 API 없는 기본형이 목표. 판매 희망가 30,000원 (사용자 상품화 최종 승인/수익성 검증 별도). 모바일 네이티브 앱, 방송국 공중 송출, DRM 우회, 음원 재판매, 외부 계정 자동 로그인, 실존 DJ 사칭은 1차 제외. AI 30~60초 작곡은 2차 선택 후속 기능으로 별도 검토.

## 2. 핵심 사용자 흐름

### A: 내 PC 음악 오프라인 방송
1) 설치 후 오프라인/온라인 선택 및 로컬 이용/음원 권리 안내. 2) 로컬 음악 폴더 추가; 원본은 읽기 전용으로 처리. 3) 기분·장르·방송 길이·선호 아티스트·회피 곡 설정. 4) DJ 스튜디오에서 실제 음색 A/B/C 선택, 차분·활기·클래식·친구·재즈 스타일, 말 빠르기·톤·멘트 길이 미리 듣기. 5) 라이선스/재생권 확인된 곡만 플레이리스트에 넣기. 6) AI DJ가 첫 곡을 소개 → 재생 → 종료 후 다음 곡으로 전환. 7) 건너뛰기/일시정지/좋아요/대화/종료 및 취향 저장. 8) 예외/재시작 시 원래 파일을 보존하고 큐 복원.

### B: 전 세계 무료 이용 가능 음악 자동 선곡
1) 선택한 음악 검색 모드에 대해 인터넷 접근·데이터 처리/서비스 제약 고지. 2) Openverse 등 공식 허용 API로 오디오 메타데이터 검색. 3) 결과의 실제 원본 페이지, 저작자, 상업적 이용/변형/스트리밍/임베딩/다운로드 조건, 라이선스 버전/고지 방식 검토. 4) source별 RightsGate가 앱 내 직접 재생 가능하다고 근거를 확인한 곡만 승인. 5) 허용된 공식 플레이어나 API 방식으로 재생. 6) 권리가 불명확하거나 서버 한도/ToS/네트워크 오류면 링크만 표시하거나 검증된 로컬 곡으로 폴백. 7) 작품별 출처·저작권 메타는 청취 화면에서 언제든 확인. **권리 검증은 검색 엔진의 license 라벨만으로 자동 승인하지 않는다.**

### C: AI DJ와 대화
텍스트/마이크 질문 → STT(오프라인 한국어 우선) → DialogueDirector/로컬 LLM 어댑터가 방송 큐와 음악 메타만 참조하여 대화·다음 곡 계획 → 사용자 선택 DJ의 실제 화자 TTS → 재생/방송 큐 반영. 생성된 멘트에서 실제 음악 저작자·곡 연혁 등은 근거가 없으면 확정하지 않는다. DJ 화자/감정 조절이 모델 미지원이면 UI에서 비활성화한다.

## 3. 사용 화면 명세
- 홈: '어떤 분위기 듣고 싶으세요?' 입력, 시간대/장르/방송 길이, 로컬/오픈 음원 모드, 마지막 방송 이어듣기.
- DJ 스튜디오: 최소 두 개 실제 다른 화자, 5개 진행 스타일(심야 감성/아침 활력/클래식 FM/친구/재즈), 미리듣기, 지원되는 감정/속도/톤 범위 선택. 스타일과 음색 혼동 금지.
- 곡 검색/권리 화면: 정확한 제목·저작자·원본 출처·라이선스 링크·변형 여부·스트리밍 허용근거, 권한 보류, 좋아요/제외.
- 재생 방송실: 큐/현재 곡/다음 곡, DJ 음성/작곡자 표시, 볼륨, 재생/일시정지/스킵/종료, 곡 출처/라이선스.
- 마이뮤직: 로컬 폴더·즐겨찾기·실재 권한 안내·취향 프로필·기록 삭제/복구.
- 설정: 모델 선택/CPU GPU/모델 팩 설치/다운로드 출처·해시, 네트워크 동의, 캐시/데이터 삭제, OSS NOTICE/약관.

## 4. 권장 데이터 흐름/모듈
입력 UI/마이크 → RequestParser(로컬 LLM 또는 룰 폴백) → StationDirector(취향·감정·기간·편성) → SourceRouter(LocalLibraryAdapter 또는 승인된 Openverse/ccMixterAdapter 등) → RightsGate(원본 페이지+음원별 상업적 사용/앱 스트리밍/표시 조건/승인시각·약관 버전) → QueuePlanner(중복방지·길이·backoff·취향 점수) → ScriptComposer(사실/창작 분리) → DJSpeechAdapter(다중 한국어 목소리·emotion/tempo, fallback) → MusicPlayerAdapter(로컬 파일 또는 허용 플레이어) → LocalSQLite(설정/편성/취향/권리 스냅샷).

각 단계는 요청 id로 중복 실행 방지; 네트워크/유료 API 기본 금지; 외부 어댑터는 별도 동의·API 사용량/한도/재시도·캐시/정책 버전 확인. 사용자 파일/개인 음성/대화 기록 외부 업로드 금지. 음원 호스팅 자체 재배포·공식 플레이어 은닉/광고 제거·DRM 우회 금지.

## 6. 음성 기술 설계
Windows SAPI는 기능 경로 시험용이며 **자연스럽고 서로 다른 DJ 목소리라는 최종 요구를 충족하지 않는다**. 상용 한국어 화자 모델 후보로 Qwen3-TTS, CosyVoice 등 조사하되 실제 코드·weights·훈련 데이터·음성 사칭/상용 재배포 허용 여부를 모델별 구분 검증할 것. 한국어 억양/숫자·외래어 발음/성별/톤/감정/쉼표/멘트 길이와 지연을 실 청취 평가. 8/16/32GB RAM, CPU-only·GPU 장치별 최초 음성 지연, p50·p95, 장시간 안정성 측정. 지원 불가능한 감정 슬라이더는 공개 금지. 음성 생성 동안 다음 멘트를 미리 합성하되 현재 곡의 권리와 스피커 출력을 안전 관리. 실존 성우/DJ 음성 클로닝/무단 학습 금지.

## 7. 음악 라이선스/저작권 규칙
- CC0: 개별 **녹음 음원**에 유효한지 원본·권리자 검증, 호스트 자동재생/원격 사용 약관 별도 확인.
- CC BY: 실제 저작자/곡명/원본 URL/라이선스 버전·링크/변형 여부 표기. 음원 저작권과 음반 녹음/실연 권리도 확인.
- CC BY-NC 등 비상업 제한, NCS '무료 감상' 범위, 권리 미확인 곡: 별도 라이선스 없으면 유료 MYRADIO 앱 자동 재생 보류.
- Openverse: 라이선스 검색 결과는 권리 진위 보증이 아니며 원본 접근·사용약관 확인 필수. ccMixter도 각 곡의 권리·스트리밍 허가 확인.
- 고객 로컬 음악: 적법한 개인용 이용 안내, 제3자 업로드/리믹스/배포 권한과 분리. 자료 업로드·임의 대량 캐싱 없음.
- 권리 회수/원본 삭제/약관 변경 시 앱 플레이어 목록에서 안전하게 제외. 이용 내역/출처 증거 보관 및 삭제권한 안내.

## 8. 보안·비용·복구

API/음악 원본 URL의 SSRF/사설 IP·리디렉션·MIME/용량/쿼터 제한. 공개 데이터가 프롬프트 명령으로 실행되지 않게 분리. 장시간 방송 큐 스냅샷·원자 저장·중복 재생·네트워크 실패시 로컬 폴백. 개인정보·비밀키 로그 저장 제한. 라이선스 SBOM/NOTICE/음악 출처 표시. EXE 코드서명/설치·제거/롤백·바이러스 오탐·지원 OS 확인. 구독 없음은 제안이지 실 판매 성능/경제성 약속이 아니며 고객 지원/플랫폼 수수료·세금 반영 필수.

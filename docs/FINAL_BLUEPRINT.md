# 최종설계도 — ECHOHOME + PAWTALK Local AI Duo
**버전 1.0 · 2026-11-13 KST · 확정 가격 및 사용자 기능 범위 반영 · 개발 미착수 · RELEASE HOLD**

## 1. 고객 문제·핵심 결정
고객의 PC에서 자기 자료를 외부에 올리지 않고 대화형 AI를 사용한다. ECHOHOME은 AI가 답한 **내용**은 기존 범용 AI와 같고, **출력 목소리만** 등록 샘플에 가까운 음색으로 바꾼다. 부모·자녀·가족·고인 등의 생애 기록을 학습하거나 그 사람 자체라고 속이지 않는다. PAWTALK는 강아지·고양이 울음소리 이벤트를 **놀이형 캐릭터의 한국어 말**로 표현하고 주인의 질문에도 대답한다. 실제 동물의 문장을 해독한다고 보장하지 않는다.

유료 API/클라우드/구독이 없는 로컬 기본형을 목표로 하며, 추후 외부 LLM/TTS API 연동은 **별도 버전·별도 동의·비용·약관 검토** 후 가능하도록 인터페이스만 분리한다. 현 버전에서 클라우드 기능을 구현·판매하지 않는다.

## 3. 사용자 시나리오 A — 가족용
1. 설치 후 AI 합성 음성 고지와 적법한 음성 이용 권한 안내를 확인한다.
2. 등록하려는 사람의 음성 파일 1~2개를 로컬 파일 선택기로 가져온다. 형식/샘플링·길이·잡음 기준 검사; 실패하면 이유와 재시도 가이드를 보여준다.
3. 오프라인으로 화자 특징을 추출·비공개 로컬 프로필 저장. 모델별 필요한 길이가 달라 음질 저하·불가 가능성 안내.
4. 고객이 문장을 미리보기로 들어 유사도/자연스러움 확인 후 활성화한다. 품질이 불충분할 땐 기본 음성으로 대화할 수 있다.
5. 마이크 버튼 누름 → 본인 질문 로컬 STT → 범용 로컬 LLM 답변 생성 → 등록 목소리 TTS 합성 → 재생.
6. 모든 답변 UI에 AI가 생성한 내용 및 합성 음성임을 표시한다. 실존 인물의 기억·의견·지식이라고 주장하지 않는다.
7. 프로필 삭제 시 원본 복사본·특징값·캐시·관련 설정을 로컬에서 삭제하고 결과를 확인한다.

## 4. 사용자 시나리오 B — 반려동물용
1. 강아지/고양이 프로필과 선호 캐릭터 목소리를 선택. 동물은 음성 복제 대상이 아니다.
2. 주인이 말할 땐 사람 마이크→STT→범용 LLM→캐릭터 TTS로 응답.
3. 동물 짖음/울음이 입력되면 VAD/오디오 이벤트 판별→확신도·주변 잡음 검사→명시적 창작 프롬프트로 **가상 표현** 생성→사람 음성으로 출력.
4. 실제 음성 의미를 알 수 없으면 '정확한 번역이 아닌 AI의 상상 표현'이라고 표시. 인식되지 않거나 오탐이 의심되면 음성 출력 안 함/수동 실행.
5. 건강 상태·불안·통증·공격성·위험 진단 금지. 동물 돌봄 관련 조언은 일반 정보로 한정하고 필요시 수의사 확인 권고.

## 5. 경량 UI·화면 정의
- 홈: 가족용 / 반려동물용 / 구매 버전 상태(오프라인)
- 가족용: 음성 파일 등록(최대 2개), 품질·권리 안내, 샘플 미리듣기, 마이크로 대화, 텍스트 입력, 일시정지, 삭제
- 반려동물용: 종 선택, 동물 이름(로컬), 캐릭터 음성 선택, '내가 질문' / '울음 감지' 토글, 감지 신뢰도 설명, 대화·중지
- 설정: 음성 장치 선택, 모델/설치 상태, CPU/GPU 지원, 저장 위치, 초기화, 오프라인 확인, 고지/OSS/라이선스
- 모두 한국어 우선, 큰 텍스트와 키보드 지원, 마이크 부재·권한 거부·무음·메모리 부족 오류 안내.

## 6. 전체 데이터/모델 경로
공통: 장치 입력→VAD/입력 정규화→로컬 STT(질문)→대화 컨트롤러→로컬 LLM→TTS 어댑터→소리 재생.
가족: 샘플파일(원본 검증)→로컬 화자 특성 추출/zero-shot conditioning→가족 TTS 어댑터; 대화 엔진과 음성 프로필 완전 분리.
반려동물: 소리 입력→동물 이벤트 감지(인식/불확실 구분)→놀이 프롬프트 컨트롤러→로컬 LLM→검증된 기본 TTS. '반려동물 말 → 실제 한국어 뜻' 변환 경로를 제공하지 않음.
저장: 모델 패키지 및 검증된 앱 바이너리(읽기 전용) / 사용자 프로필·필요한 음성 샘플·설정(AppData 하위) / 작업 캐시(세션 종료 시 삭제). DB 서버·클라우드·고객 자료 업로드 없음.
부팅 중 인터넷 없을 때에도 모델/오디오 엔진 모두 실행되어야 함. 설치 패키지에 허용되는 모델을 오프라인 번들로 담거나 별도 로컬 모델 팩을 배포, 숨은 다운로드와 과금 금지.

## 7. 실현 가능한 1차 범위와 명시적 제외
포함: 1~2개 가족 샘플 로컬 입력, 샘플 미리듣기/대화 음성 출력, STT+LLM+TTS, 가족/동물 각 모드, 설정·삭제·고지·오프라인 설치/실행.
제외: 과거 기억 학습, 고인의 생전 발언인 척 응답, 음성파일 1개만으로 **항상 동일인 수준 재현** 보장, 다른 앱의 음성을 즉시 가로채는 OS 오디오 후킹, 전화/메신저 통화 플러그인, 음성 합성 대량 추출, 보이스피싱 자동화, 실제 동물 언어 번역, 수의학 진단, 클라우드 계정·API 대행, iOS/Android, 실시간 자막 번역, 사용자 가족의 화자 여러 명 동시 합성.

## 8. 안전·권리·데이터·위협
- 등록 시 이용자가 해당 음성의 적법한 이용권을 가졌음을 확인. 자기 음성·충분한 당사자 동의 자료를 우선. 사망자 음성은 가족관계 자체가 무조건적 이용 허가를 뜻하지 않으므로 출시 전 별도 법률·권리 검토.
- 고객 소리나 원본을 외부 전송하지 않고 경로/권한/파일 종류·길이 제한. 앱 자동업데이트·원격 로그 수집·분석기·텔레메트리 기본 비활성.
- AI 음성 및 AI 답변임을 세션 시작과 재생 화면에서 표시. '실제 돌아가신 분이 말한다' 또는 '정확한 반려동물 번역' 표현 금지.
- 실존 인물 사칭·전화 연결·대량 배치/파일 추출 API를 넣지 않는다. 녹음 외부 재유출까지 기술적으로 100% 막을 수 있다고 주장하지 않는다.
- 보존 기간: 원본 복사본 선택 보유 여부를 고객에게 설명, 기본적으로 프로필 삭제 가능, 로그 미수집; 시스템 백업/휴지통 등 삭제 한계를 명시.
- 규제/분쟁: 한국 AI 생성물 고지·개인정보·초상/성명/음성 권익·소비자판매/환불 및 모델 약관의 법률 검토를 출시 게이트로 둔다.

선정 기준: 오프라인 검증, 실제 목소리 유사도/한국어 발음, CPU/일반 GPU 지연, 상업적 **가중치 재배포 허용**, 악용 위험, 유지보수. 구체 모델은 실측/라이선스 통과 후 결정하고 미검증 상태로 브랜드·모델 성능을 확정하지 않는다.

## 10. 구현 모듈·경계·오류 복구
- app_ui: 화면/설정/마이크 권한/선택 및 로컬 고지.
- audio_io: 마이크/VAD/오디오 형식 유효성, 재생 장치 선택·취소.
- asr_adapter: 한국어 질문 인식, 무음·소음/모델 오류 처리.
- dialogue_adapter: 로컬 LLM 프롬프트/역할·세션 데이터 격리, 스트리밍 불능 시 오류.
- human_voice_adapter: 화자 샘플 검증/특성/미리듣기/합성 실패 시 기본 음성 폴백.
- pet_event_adapter: 짖음/울음 분류가 신뢰도 낮으면 보류; 사실적 번역 아님을 UI 노출.
- default_tts: 캐릭터 미리듣기·한국어 합성.
- storage: 로컬 경로/메타/프로필 삭제 및 모델 캐시 관리; 파일 원본 비변경.
- installer: 모델 가중치·사용권·버전 hash, 오프라인 패키징, Windows 설치·복구·제거.
- sku_license: 단일/묶음 기능 선택과 환불/고객지원; 서버 인증·DRM은 1차 기본 요건이 아님.

이벤트마다 유일한 session/request id를 로컬 메모리에서 유지. 마이크 중복 입력/중복 생성 요청은 취소, 재생 시작·종료 상태를 UI에 표시. 중도 실패 시 외부 호출 없이 안내 후 재실행하며 기존 원본 파일/프로필을 원자적으로 유지. 음성 원본을 모델 학습 DB로 저장하지 않는다. 네트워크 실패가 아닌 GPU/CPU 메모리 부족을 별도 진단.

## 12. 주요 실패 가설·대안
- 단 한두 음성 파일에서 유사도 저하: 길이/잡음 안내 + 미리보기 + 기본 음성 폴백; 충족하지 못하면 '1~2개로 재현 보장' 문구 금지.
- CPU 사용 중 답변 지연/고장: 더 작은 합법 모델·경량 실행기 대안 측정; 클라우드 무단 전환 금지.
- 반려동물 이벤트를 사람말로 잘못 해석: 이벤트 감지만 보수적으로 제공, 불확실하면 창작 모드만 표시·정정 가능.
- 상업용 모델 재배포 불가: 호환 모델로 교체하거나 개발 보류; 사용자에게 미승인 유료 라이선스 강요 금지.
- 음성 사칭 악용: 권리확인, 사용처 제한, 생성음 고지, 통화·대량 추출 배제; 잔여 위험 및 대응 한계 공개.
- Windows 패키지 손상/보안 소프트웨어 오탐: 서명/무결성 검증·배포 전 실제 사용자 PC 피드백; 원본 자동 삭제 없이 uninstall 롤백.

## 13. 이번 작업 결과와 나머지
이 문서는 사용자가 확정한 제품 범위/가격을 **개발 가능한 최종설계 문서**로 고정하기 위한 것. 소스 구현, 모델 선정, 오프라인·성능·라이선스·실고객 수용 테스트, 법률 확인 및 크몽 실제 상품 등록은 아직 진행되지 않았으며 승인 후 단계적으로 처리한다.

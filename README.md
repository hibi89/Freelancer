# ECHOHOME + PAWTALK — 개인용 로컬 음성 AI 듀오

- 역할: 두 개의 크몽 설치형 소비자 상품을 한 개발 브랜치에서 설계/개발. 공개/판매 전 별도 출시 승인.
- 브랜치: product/echohome-pawtalk-local-ai
- 확정 판매 희망가: **ECHOHOME 30,000원 / PAWTALK 30,000원 / 묶음 50,000원**. 가격은 소유자 결정, 세금·수수료·지원 범위는 출시 전 검토.
- 공통 기반: Windows 로컬 설치, 마이크 입력, 로컬 대화 모델, 출력 음성, 사용자 데이터 로컬 유지, 기본형 API/월 과금 없음(검증 전 광고 금지).
- **ECHOHOME(가족 목소리 AI 대화)**: 권한 확인된 사람의 샘플 음성 1~2개 등록 → AI의 일반적인 답변을 그 음색/톤으로 출력. 기억·성격·유품 학습/사람의 실존 재현 없음.
- **PAWTALK(반려동물 캐릭터 대화)**: 강아지/고양이 소리를 이벤트로 감지하여 AI가 상상형 사람 말투로 응답. 주인과 음성 대화. 실제 동물 언어를 번역하는 제품이 아님.
- 현재: **기획/설계 브랜치, 기능 미구현, 최종설계 기준 UNASSESSED, RELEASE HOLD, 크몽 미등록**.
